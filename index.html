01 · Asset audit

What the source assets establish

The supplied material contains a current institutional identity, a 2025 learning-product guide, a large education-icon family, and real admin screenshots. It contains enough evidence to define a system, but not every historic treatment deserves to survive.

Durable evidence

Navy, turquoise, vermilion and warm grey recur across 2025–26 brand material. Montserrat governs interface copy; the italic display face is expressive and deliberately limited. The shield/V mark makes framed, open geometry a stronger cue than rounded “SaaS” cards.

Current authority

The February 2026 identity has consistent logo variants, colour values, and a clear institutional posture. It is the authority for all new digital work, with navy as the structural anchor and vermilion as a sharp, selective signal.

Normalise, do not copy

The CRM proves the need for dense records, tables, tabs and clear workflow status. Its multi-colour tiles, mixed icon modes, heavy borders and Bootstrap-like controls are legacy implementation choices rather than visual rules.

02 · Visual DNA

Institutional confidence with an active edge

Versable belongs neither to a cold corporate system nor an informal learning app. Its character comes from disciplined structure, purposeful colour interruption, and occasional editorial contrast.

Geometric, open

Shield contours, brackets, and the V imply containment with an opening. Use frames, rules and aligned edges; avoid soft, floating blobs.

Dense when useful

Administrative screens earn compact tables and repeated metadata. Marketing and learning reflection moments introduce more room, not gratuitous cards.

Restrained colour

Navy establishes order. Turquoise identifies active learning or secondary action. Vermilion calls attention. Accent colours do not become a decorative rainbow.

Editorial punctuation

Benton italic provides a human, intellectual lift only in display text. The interface remains direct, legible Montserrat.

Primitives are ingredients; semantic tokens are the contract

Semantic usage

color.background.primary supports everyday reading. color.action.primary.default is navy with white text. Turquoise is a surface/action accent, never small text on white. Vermilion uses a darkened semantic alias for interactive text and destructive actions.

Theme posture

Light mode is complete. The package includes [data-theme="dark"] foundations for inverse surfaces, text, borders and links. Do not ship a full dark mode until its component states have been reviewed.

Implementation token structure

color.primitive.navy.900 → color.action.primary.default → Button primary. The downloadable tokens.json is platform-neutral; tokens.css exposes CSS custom properties.

05 · Grid and responsive rules

Order carries across a reading page and an academic record

Standard content tops out at 1200px, reading content at 704px, and wide data views at 1440px. Use 12 columns at desktop, eight at tablet, and four at mobile. Gutters are 32px desktop and 16px mobile.

Mobile ≤ 640px

One primary column; navigation collapses into a horizontal or disclosure pattern; tables preserve columns in a labelled horizontal scroll container.

Tablet 641–1024px

Two-column support layouts; no critical action lives only in a hover state; side content follows the task content in source order.

Desktop ≥ 1025px

Persistent navigation works for admin contexts. Keep task actions within their panel header; use density to reveal relationships rather than shrinking type.

06 · Logo and iconography

The mark remains untouched; the system clarifies its use

Logo rules

  • Use supplied full lock-ups and mark files only; never redraw, skew, crop or outline them.
  • Clear space: at least the inner width of the shield’s red V on every side.
  • Minimum digital width: 132px for the full lock-up; 28px for the standalone mark.
  • Use navy, white or approved turquoise variants against solid, high-contrast backgrounds. Do not place on busy images or low-contrast turquoise.

24px interface icon system

New UI icons use a 24×24 grid, 2px rounded caps/joins, one visual weight, and current text colour. Existing illustrated learning icons remain valid as labelled learning-resource markers, usually at 48–64px.

Normalisation strategy

Do not mix flat, line and full-colour illustrations inside one compact control strip. Use line icons for navigation and actions, flat icons for simple resource categories, and colour icons for prominent learning-object entry points. Pair every non-decorative icon with a visible or programmatic label.

09 · Accessibility and motion

Clarity reinforces the brand

Non-negotiable interface rules

  • Normal text uses at least 16px; compact metadata never carries essential information alone.
  • Keyboard users receive a 3px turquoise focus ring with offset. Never rely on a faint shadow.
  • Every field has a persistent label; errors name the problem and the recovery action.
  • Status combines colour, plain language and an icon or label. Tables keep headers and scroll access.
  • Target size is 44px minimum for touch-relevant controls; tooltips never contain essential content.

Motion principles

  • 120–180ms transitions for hover, focus and selection; 280ms maximum for expansion.
  • Motion explains state change: reveal a panel, confirm a save, advance progress. It never decorates an idle page.
  • Respect prefers-reduced-motion; avoid autonomous movement, parallax and delayed navigation.
  • Loading states name the in-progress work and preserve user input after recoverable failure.

✓ Do

Use a navy panel header, firm dividers, compact information grouping, expressive display type only at meaningful editorial moments, and a single decisive action.

× Don’t

Turn every section into a rounded card, use turquoise or vermilion as small text on white, mix all three icon modes in one toolbar, add gradients, or make a generic rainbow dashboard.

10 · System gaps

Decisions requiring validation as the system grows

Full dark theme

The brand clearly supports navy environments, but supplied assets do not establish all dark component states. Keep dark foundations only; test and approve each semantic component mapping before release.

Data visualisation

Legacy charts use arbitrary dashboard colours. Establish a separate, ordered data palette and non-colour labels before adding reporting charts to the system.

Mobile learning flows

The evidence is desktop-heavy. Validate module navigation, resource completion and assessment flows with learners before defining a permanent mobile pattern.

Illustration ownership

Existing resource icons are strong but stylistically varied. Keep them for known learning types; approve a reusable drawing grid and illustrator brief before expanding the set.

Final recognition test: remove the logo and name. The remaining navy structure, shield-like framed geometry, precise type hierarchy, selective vermilion/turquoise, and dense-but-orderly learning/admin patterns should still feel recognisably Versable.
